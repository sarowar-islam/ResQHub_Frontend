Create a complete modern UI/UX design for a responsive multi-page disaster management web application called "ReliefLink".

The application is designed specifically for disaster response during floods, cyclones, landslides and similar emergencies in Bangladesh.

The goal of the platform is to connect disaster victims, volunteers and NGOs into one centralized platform where help requests, rescue operations and relief distribution can be managed efficiently.

This is ONLY the frontend design.

Do not connect any backend.

Every page should be fully functional using mock/demo data stored in separate data files (dummy.ts, mockData.ts or similar architecture depending on the framework). Design every screen as if backend APIs already exist so replacing the dummy data with REST APIs later becomes straightforward.

There should be absolutely no dead UI. Every button, card, modal, dropdown, filter, notification, map marker, table and interaction should demonstrate realistic behavior using mock data.

The design must be fully responsive and optimized for Desktop, Tablet and Mobile.

The design style should be modern, premium, minimal and highly professional similar to products from Stripe, Linear, Notion, Vercel and Airbnb.

Avoid unnecessary gradients or flashy colors.

Use a calm emergency-response color palette:

Primary:
Deep Blue

Secondary:
Teal

Accent:
Orange for alerts

Success:
Green

Danger:
Red

Background:
Very light gray

Cards:
White with soft shadows

Rounded corners around 12-16px.

Use excellent spacing and typography.

Icons should come from Lucide Icons.

Animations should be subtle.

Use skeleton loaders wherever appropriate.

Support Light Mode.
